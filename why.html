AIBAST Agents Library

Why the RAPP Brainstem?

It is a local frontier learning and rapid prototyping tool. It is where you learn the agent pattern and prove a prototype on your own machine, before the result graduates into the Microsoft tools that carry it to real users.

What it is

A small local server, powered by GitHub Copilot, that runs the RAPP agent loop: read a soul file, discover agents, call the model with tools, execute the tool an agent exposes, and answer. Every agent is one Python file. Agents reload from disk on every request, so the loop from idea to working prototype is measured in minutes, with synthetic data and no cloud to provision.

The library's industry solutions, the production guide, and the Academy workshops all assume this loop exists on the learner's machine. That is the whole job of the Brainstem: make the pattern learnable by running it.

What it is not

  • Not a replacement for GitHub Copilot. Copilot is the work surface and the model. The Brainstem borrows Copilot's access so there are no keys to manage, and it hands the work back to Copilot the moment you are done learning.
  • Not a competitor to Copilot Studio or Microsoft 365 Copilot. Those are where a finished agent lives. The Brainstem is where the agent is first understood, and the library ships the Copilot Studio solution for every workshop precisely so the prototype can leave.
  • Not a production runtime. Nothing here is built to serve users. It is built to teach one person at a time, quickly.
  • Not a second platform to standardise on. The RAPP/1 wire is one endpoint, POST /chat, and a skill or agent written for it promotes into first-party tooling without a rewrite.

Why local, and why "frontier"

The fastest way to learn an agent pattern is to change one file and see the behaviour change. Doing that against a cloud tenant means provisioning, permissions, publish cycles, and someone else's data. Doing it locally means the loop is yours, the data is synthetic, and nothing you try can reach a customer.

Frontier is the honest word for what happens there: new model behaviour, new tool shapes, and new industry patterns get tried in the Brainstem first. The ones that hold up are written into the production guide and shipped as first-party solutions. The ones that do not are deleted, cheaply.

The graduation path

The library calls these the Brainstem, the Hippocampus, and the Nervous System. The names are a mnemonic for the same idea: start with the survival loop, add memory and a cloud body when you need them, then connect to the enterprise nervous system. You advance when you choose to.

How it stays out of the way

  • No keys. GitHub Copilot's token exchange is the only credential, and it is yours.
  • One file per agent. Portable, reviewable, diffable. The Copilot Studio export for a workshop is generated from the same source.
  • One wire. POST /chat in, a response out. Any host that can read a URL and use a terminal can drive it, including GitHub Copilot in VS Code or the Copilot CLI, Claude Code, and Microsoft Scout.
  • Leaves cleanly. Uninstall is deleting one folder. What you learned is in the skill file, not in the server.

Who it is for

Sellers, architects, and partners who need to understand an agent pattern well enough to explain it and adapt it, and workshop learners who want to build one before they publish one. If you already know what you want to ship, go straight to the library and take the Copilot Studio solution. If you want to understand it first, install the Brainstem.
