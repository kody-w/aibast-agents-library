Scan a skill

Point this at your own skill.md — one file, a raw URL, or a whole repository of them. It runs the same rubric this library runs on itself, tells you what will drift and why it matters, and shows you the deterministic RAPP version of your file. Attach your own intelligence

The rubric above is deterministic — it measures, and measurement is not judgment. The interpretive residents (clarity, honesty, blast radius, teachability) need a model, and this page has none: no endpoint, no key, no calls out.

Download the packet below and execute it against whatever model you use, then feed the answers back with sentinel.py absorb. Or clone the neighborhood and run the whole thing yourself — python3 scripts/sentinel.py run needs no token and no service. The rubric is a JSON file; disagreeing with a check means editing data, not us.
