RAPP Certified

Publishers who have shipped an agent that passed review are listed on a public roster, and every one of them gets a verification endpoint keyed to their GitHub username. Anyone can check a claim — no login, no API key. Revocation is immediate: the same URL keeps resolving and simply answers certified: false.

Badges

The API ships a shields.io endpoint, so any README can display live library numbers. Copy a line and paste it into yours.

Badges read api/v1/badge.json, which the daily build regenerates. Point shields at any of the other endpoints the same way to surface your own numbers.

Integrate it

The contract is documented in docs/API.md: versioned endpoints under api/v1/, a schema and generated stamp on every document, and a stable-write build so a rebuild with no change produces no diff. It follows the rapp-static-api/1.0 convention — the repository is the API.

Two hosts, same bytes GitHub Pages (microsoft.github.io/aibast-agents-library/api/v1/) and raw (raw.githubusercontent.com/microsoft/aibast-agents-library/main/api/v1/). Both are CDN-cached and send Access-Control-Allow-Origin: *.
No key, no quota Static files. Nothing to authenticate, nothing to rate-limit, nothing to page.
Pin what you ship Swap main for a commit SHA in the raw URL and the response is immutable forever.
