Where these numbers come from

Downloads combines four things: full copies of the library, individual agent files fetched from the public content network, release package downloads, and tracked installs. Only a rolling 14-day window is available upstream, so a snapshot is taken every day and accumulated by date — totals grow from the first day of tracking and never double-count.

On copies. Automated builds count as copies too, and this library runs scheduled builds, so that figure is partly self-generated. Tracked installs — one per person, per agent — is the narrowest and most trustworthy number on this page: it reads as unique installers per agent.

On engagement. Upvotes are positive reactions on an agent's public review thread. Negative reactions never count toward a score, and one person can only react once. Comment counts exclude the automated bookkeeping the library posts itself. Every count here is people, not clicks.
