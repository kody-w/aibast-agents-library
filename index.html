Three tiers, taken one at a time

Each tier stands on its own and each one is optional. Most people stay on the first for a long time.

Tier 1

The Brainstem

A private agent server on your own machine
Start here

The biological brainstem keeps you alive — breathing, heartbeat, reflexes. This one does the same job for an agent: it runs the core loop, calls the tools, and answers. Everything else builds on top of it.

Run the one command

This is the only step. It installs what is missing, sets everything up, signs you in, and launches.

curl -fsSL https://microsoft.github.io/aibast-agents-library/install.sh | bash

On Windows, run this in PowerShell instead:

irm https://raw.githubusercontent.com/microsoft/aibast-agents-library/main/install.ps1 | iex
Advanced — do it step by step

1. Sign in with GitHub

Your GitHub Copilot subscription is the AI engine. There are no other keys to obtain.

gh auth login

2. Start the server

It comes up on port 7071 with a chat window, a health check, and automatic discovery of any agents you have added.

brainstem

3. Talk to it

Open localhost:7071 in your browser.

curl -s localhost:7071/health | python3 -m json.tool

4. Make it yours

Give it a personality, then drop in agents from the library to give it skills. Everything stays on your machine.

Tier 2

The Hippocampus

Memory that lasts — runs local, deploys to Azure
Next step

The hippocampus is where memories form. One command sets up everything needed to give your agents a memory that survives restarts — and the same project deploys to Azure when you are ready. No Azure account is needed to try it.

Run the one command

This is the only step. It sets up the cloud-shaped version of the server locally, installs what it needs, and tells you what to do next.

curl -fsSL https://raw.githubusercontent.com/microsoft/aibast-agents-library/main/rapp_cloud/install.sh | bash

On Windows, run this in PowerShell instead:

irm https://raw.githubusercontent.com/microsoft/aibast-agents-library/main/rapp_cloud/install.ps1 | iex

Read the full onboarding guide

Advanced — do it step by step

Start it and sign in

Open the chat window and send a message. It walks you through signing in — there is nothing to configure first.

cd ~/rapp-projects/my-project && ./start.sh

Deploy to Azure when ready

Add your Azure OpenAI details, then publish.

func azure functionapp publish YOUR_APP_NAME --build remote

Or deploy straight from the Azure portal:

Check the deployment

curl -s https://YOUR_APP_NAME.azurewebsites.net/api/health | python3 -m json.tool
Tier 3

The Nervous System

Copilot Studio and Teams — reach your whole organisation
Advanced

Your nervous system extends your brain's reach to every part of your body. Copilot Studio does the same for an agent: it connects to Teams, to M365 Copilot, and to the rest of the Microsoft stack. The agent you tested on your laptop becomes the agent your colleagues use.

1. Download the ready-made solution

A single package containing the agent, its connectors, and its flows, already wired for your own cloud service.

Download the solution (v1.0.0.6)

2. Import it into Power Platform

Go to make.powerapps.com, then Solutions, then Import, and upload the package. It creates the Copilot Studio agent and its flows in your environment.

3. Point it at your service

Open the imported flow and set its address to the cloud service you deployed in Tier 2. Add a key if you are using key-based access.

4. Publish to Teams and M365 Copilot

Publish from Copilot Studio and your users can talk to it wherever they already work — the same agent logic, now organisation-wide.
