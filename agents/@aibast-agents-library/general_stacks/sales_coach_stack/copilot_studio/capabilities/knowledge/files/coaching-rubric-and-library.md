## Call scoring rubric

The overall call score is the weighted sum of the six skills, rounded to the
nearest whole number. Weights sum to 1.00.

| Skill | Weight | Criteria |
|-------|--------|----------|
| Opening | 10% | Warm greeting and rapport; agenda setting; time confirmation; reference to previous interactions |
| Discovery Questions | 25% | Open-ended questions; pain point identification; budget qualification; timeline discovery; decision process mapping |
| Active Listening | 15% | Paraphrasing; acknowledgment phrases; follow-up on responses; note-taking signals |
| Value Articulation | 20% | ROI quantification; customer-specific benefits; competitive differentiation; social proof/references |
| Next Steps | 15% | Clear action items; mutual commitment; timeline specified; calendar invite sent |
| Objection Handling | 15% | Acknowledge concern; clarifying questions; reframe with value; proof points; trial close after handling |

Worked example (CALL-901):
`85*0.10 + 72*0.25 + 90*0.15 + 68*0.20 + 95*0.15 + 60*0.15`
`= 8.5 + 18.0 + 13.5 + 13.6 + 14.25 + 9.0 = 76.85 -> 77`

## Coaching activity library

The library is keyed by the rubric's skill names. Rep-level focus areas use
the short names (objections, value, discovery, listening, opening, closing),
which do not match these keys — so a plan built from a rep assessment falls
back to the general objection-handling set. Say so when it happens.

### objection_handling

| Activity | Duration | Frequency | Resource |
|----------|----------|-----------|----------|
| Role-play: Price Objection Scenarios | 30 min | 2x/week | Objection Handling Playbook Ch. 4 |
| Review 5 recorded calls where objections were handled well | 45 min | 1x/week | Call Library - Top Performers |
| Practice the Feel-Felt-Found framework | 15 min | Daily | Sales Methodology Guide |

### discovery_questions

| Activity | Duration | Frequency | Resource |
|----------|----------|-----------|----------|
| SPIN Selling question practice | 20 min | Daily | SPIN Selling Workbook |
| Shadow top performer discovery calls | 60 min | 2x/week | Peer Coaching Program |
| Complete BANT qualification checklist review | 15 min | After each call | Qualification Framework |

### value_articulation

| Activity | Duration | Frequency | Resource |
|----------|----------|-----------|----------|
| Customer ROI case study review | 30 min | 3x/week | Customer Success Stories Library |
| Practice value proposition delivery | 15 min | Daily | Value Prop Toolkit |
| Create custom ROI calculations for top 5 prospects | 45 min | 1x/week | ROI Calculator Tool |

## Coaching plan constants

| Setting | Value |
|---------|-------|
| Focus areas per plan | 2 (the two lowest skill scores, ascending) |
| Goal | Improve weakest skills by 15+ points in 30 days |
| Timeline | 4-week program with weekly check-ins |
| Success metrics | Skill score improvement, call conversion rate, quota attainment |
