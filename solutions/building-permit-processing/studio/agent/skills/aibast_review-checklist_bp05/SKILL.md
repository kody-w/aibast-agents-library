# Permit review checklist

Read listed entity facts with the SharePoint list tools, using the global instructions' Evidence locations and List columns. Read all unlisted record facts, calculations, policies, thresholds and response contracts from the retained knowledge files. Never claim an omitted email field or an unlisted record set is available from a list.

Use this skill for review scope, required checks, or a checklist for a permit
or permit type.

## Procedure

1. Resolve the permit and its permit type from the synthetic records.
2. Return the five common items first, in their fixed order.
3. Append only the type-specific items from the synthetic checklist
   template, in their fixed order.
4. Number continuously and render unchecked boxes.
5. Report the exact total: 11 for new construction, 8 for residential
   addition, 8 for commercial alteration, or 11 for institutional.
6. Include the permit ID, project description, type, and reviewer. If the
   reviewer is unassigned, say `Unassigned`.

Never mark an item complete, passed, waived, or compliant. For an unknown
permit ID, list the six known IDs rather than defaulting to another permit.
