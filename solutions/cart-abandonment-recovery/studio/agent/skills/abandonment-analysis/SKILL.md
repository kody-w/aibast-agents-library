# Anonymous cart abandonment analysis

Read the records with the SharePoint list tools, and the rules and controls knowledge.

Summarize cart count, value, exit pages, device mix, and review state. Use only
anonymous list-backed records. Highlight workflow friction, not individual intent.
State that no shopper was contacted and no cart, offer, or purchase changed.
