Curate sources before they curate you.

This librarian is a Reddit-style review surface for agent and skill libraries. It separates first-party sources from subscribed, quarantined, and community-suggested sources so trust state is explicit rather than inferred from a link. Every discovered item is namespaced as library-slug:item-slug; bare slugs are never globally trusted.

Browser safety boundary This page reads only generated local catalogs and committed metric/Discussion sidecars. It never fetches, imports, renders, or executes content from a source URL. Remote acquisition and validation belong to approved CI or a trusted backend after maintainer review; this browser has no client token. Existing agent ratings or Discussions are not treated as a trust signal for an external library source. Authenticated library-source suggestions belong in Ideas; approved namespaced catalog item threads belong in Announcements.
