# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/aibast-agents-library/issues)
to track bugs and feature requests. Please search the existing issues before
filing new ones to avoid duplicates. For new issues, file your bug or feature
request as a new Issue.

For help and questions about using this project — agents, the installers, the
in-browser runtime, publishing, or the static API — please use
[GitHub Discussions](https://github.com/microsoft/aibast-agents-library/discussions).

## Microsoft Support Policy

Support for the AIBAST Agents Library is limited to the resources listed
above. This is a community-supported public preview provided "AS IS" — see
[DISCLAIMER.md](DISCLAIMER.md); there is no paid-support channel or SLA.
