# Support

This repository is an experimental AIBAST project, not an officially supported
Microsoft product. No service-level agreement or production support commitment
is provided.

## Public questions

Use [GitHub Discussions](https://github.com/microsoft/aibast-agents-library/discussions)
for public usage questions and workshop discussion. Do not include credentials,
internal URLs, tenant IDs, customer data, proprietary code, or unnecessary
personal information.

## Bugs and feature requests

Use the repository's structured GitHub issue forms. Blank issues are disabled so
reports include the affected area, version or revision, and actionable evidence.
Review the complete public payload before submitting it.

## Security vulnerabilities

Do not report security vulnerabilities through public issues or Discussions.
Follow [SECURITY.md](SECURITY.md) and the current Microsoft Security Response
Center guidance at <https://aka.ms/SECURITY.md>.

## Badge and public profile records

The badge program is not operational until the workflow and static outputs
defined in [docs/badge-program.md](docs/badge-program.md) launch together.
When enabled, completion issues and profile updates are governed workflow
records. Raw quiz answers and private evidence are never public. Profile
inclusion may be corrected, suspended, or removed under the published rules.

## SharePoint access

If the badge roster is enabled, it does not grant SharePoint or tenant access.
Maintainers handle SharePoint library access manually.
