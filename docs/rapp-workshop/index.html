Use case in. Copilot Studio solution out.

For this workshop, RAPP means a guided Documents to Copilot Studio process with explicit human gates before generation, deployment, and publication.

Experimental training content. This material is maintained by an AIBAST v-team and is not an officially supported Microsoft product or production deployment guide. Generated output may contain errors and requires human review.

The five-step RAPP process

Participants learn by doing. Nothing is built or deployed without an explicit decision.

1

Sign in

Authenticate generation and environment access.

2

Documents

Upload focused, approved evidence and name the solution.

3

MVP

Read, edit, re-derive, or confirm the use case.

4

Review

Inspect agent files plus demo and live solution twins.

5

Deploy

Choose an environment, import, test, and publish deliberately.

60-minute run of show

00-10
Align. Set the outcome and explain the five-step mental model.
10-15
Scenario. Identify the user, problem, outcome, and safety boundary.
15-23
Sign in + documents. Authenticate and upload approved inputs.
23-31
MVP gate. Read aloud, correct, and confirm.
31-41
Generate + review. Inspect capabilities, agent files, and solution twins.
41-51
Deploy. Import into the workshop environment.
51-57
Test. Run happy, edge, safety, and unknown-value prompts.
57-60
Teach back. Explain the process, show one artifact, and name the next change.

Rehearse before you facilitate

1. Technical path

Use a clean browser and the included inputs. Generate, review, import, and test in 35 minutes or less.

2. Facilitation path

Deliver the full deck against a timer. Protect the MVP, deployment, test, and teach-back blocks.

3. Contingency path

Practice sign-in, wrong-MVP, generation, import, and live-connection failures. Recover within three minutes.

No-PII and responsible-use posture

Permission

Use only information the customer is authorized to process. Never request credentials, secrets, or unauthorized production data.

Proof

Verify the MVP, capabilities, systems, and generated answers with a human reviewer.

Production

Complete security, data, connection, DLP, testing, and publication reviews before go-live.

The current workshop uploader supports PDF, DOCX, PPTX, XLSX, TXT, MD, CSV, JSON, RTF, HTML, and agent source/ZIP files. OCR image-only notes or place readable text into a supported document before upload.
