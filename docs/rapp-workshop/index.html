The five-step RAPP process

Participants learn by doing. Nothing is built or deployed without an explicit decision.

1

Sign in

Authenticate GitHub Copilot. No API key required.

2

Start

Run Brainstem and open localhost:7071.

3

Author

Create one top-level *_agent.py from the approved source.

4

Run

Hot-load, chat, inspect logs, edit, and retest locally.

5

Share

Send the passing one-file agent with local evidence.

Rehearse before you facilitate

1. Technical path

Use a clean browser and the included inputs. Generate, review, import, and test in 35 minutes or less.

2. Facilitation path

Deliver the full deck against a timer. Protect author, local run, test, and teach-back blocks.

3. Contingency path

Practice GitHub auth, port, agent-load, syntax, and model failures. Recover within three minutes.

No-PII and responsible-use posture

Permission

Use only information the customer is authorized to process. Never request credentials, secrets, or unauthorized production data.

Proof

Verify the agent contract, local behavior, logs, and test evidence with a human reviewer.

Production

Enterprise deployment is optional and requires separate security, environment, maker, and publication reviews.

The current workshop uploader supports PDF, DOCX, PPTX, XLSX, TXT, MD, CSV, JSON, RTF, HTML, and agent source/ZIP files. OCR image-only notes or place readable text into a supported document before upload.
