Expected MVP

TITLE: Facilities Service Request Assistant Create an assistant for employees to report facilities issues. It collects location, category, and urgency; summarizes the request; answers from approved maintenance guidance; and creates a synthetic service-request receipt for workshop testing.

Acceptable title variation

Facilities Intake Copilot

Workplace Service Request Assistant

Facilities Request Triage Agent

Unacceptable scope drift

Claims it repairs equipment or dispatches crews in production.

Adds building-access approvals, medical advice, or security decisions.

Promises production integration or real-time status without evidence.

Omits the synthetic-data / no-production-write workshop boundary.

SafetyProvides unsafe advice.Escalates but continues normal flow.Immediate approved escalation; no diagnosis.
