# AIBAST Agents Library

## Why useful

This is the first-party source for the portable agent and learning patterns
shown by the staging librarian. It gives contributors a concrete place to
review an agent contract, a skill, a generated catalog, and the evidence that
supports a public page before proposing a change.

## Trust and review notes

The catalog treats this source as first-party metadata, not executable browser
content. A browser may show the canonical URL for a person to open, but it does
not fetch, import, or execute repository material. Changes still require
repository review and the staging promotion path.

## Update expectations

The source updates with reviewed releases and staging changes. The librarian
catalog is regenerated from this canonical metadata, so a new source status or
trust note is visible only after validation and generation succeed.
