# Internal workshop videos & one-pagers

## Why useful

This source represents limited internal workshop materials that can support
approved learning and demonstration scenarios. The public catalog exposes only
safe asset identifiers, titles, and descriptions so a requester can identify
the right material without seeing a private location or receiving the material
through the public site.

## Trust and review notes

Requests are discretionary and least-privilege. An owner reviews the public
GitHub request, verifies that it contains only a non-sensitive business
justification, and manually grants the requesting GitHub account access to the
selected asset through an approved private channel. Owners never post private
links or restricted asset details in the public issue.

## Update expectations

Asset availability is owner-managed and may change without notice. The public
catalog records only approved, denied, or fulfilled request status and
aggregate counts. It does not profile requesters, publish private locations, or
execute or fetch restricted material in a browser.
