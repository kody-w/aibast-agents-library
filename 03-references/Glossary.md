# AIBAST Glossary

Terms are alphabetical. Meanings describe their use in this repository, not
an assurance about a deployed customer system. Each source links to the
governing definition or a concrete package example.

| Term | Meaning | Source |
| --- | --- | --- |
| Achievement points | Self-paced workshop milestones recorded in local browser progress. Optional GitHub-verified sync is separate; Academy completion is not an official credential. | [Package progress rules](../solutions/README.md), [Academy positioning](../README.md) |
| Agent manifest | The `__manifest__` dictionary inside an agent's Python file, carrying identity, version, description, and other registry metadata. The builder reads it without executing the agent. | [Constitution](../CONSTITUTION.md) |
| AIBAST | Artificial Intelligence Business Applications Specialist Team, the team whose ecosystem this agent library serves. | [Constitution](../CONSTITUTION.md) |
| Brainstem | Tier 1: the local Flask runtime that uses GitHub Copilot for conversation and tool calling. It is a learning and prototyping environment, not the end-user product to ship. | [Tier definitions](../CLAUDE.md), [project positioning](../README.md) |
| Brainstem track | The optional GitHub Copilot + Brainstem Easy-mode lane. Brainstem supplies local workshop context and visible agent execution; Copilot still performs the build and deployment work. | [Facilitator and delivery guide](../solutions/ask-hr/FIELD-GUIDE.md) |
| Browserfilm | A labeled GIF and contact sheet built from real browser screenshots, with raw frames and a manifest retained for audit and rebuilding. Mock screens are not evidence. | [Browserfilm rules](../tools/rapp-browserfilm.md) |
| Catalog | `solutions/catalog.json`: hand-authored business and architecture copy for solutions. Distinct from the generated agent registry. | [Source-of-truth boundaries](../solutions/README.md), [catalog](../solutions/catalog.json) |
| Demo case | A locked persona-language test prompt with the expected agent and source-backed output assertions. It tests routing and behavior rather than requiring identical model prose. | [Agent Constitution](../agents/@aibast-agents-library/AGENT_CONSTITUTION.md), [Ask HR cases](../tests/demo_cases/ask-hr.json) |
| Deployment recipe | `deployment.json`: the machine-readable source, installation, tool, and smoke-test contract used by GitHub Copilot Agent mode for no-terminal installation. | [Recipe ownership](../solutions/README.md), [Ask HR recipe](../solutions/ask-hr/deployment.json) |
| Draft | The unpublished Copilot Studio state used as the workshop stopping point, recorded as `published: false`. Publication requires a separate authorized decision. | [Draft gate](../solutions/ask-hr/FIELD-GUIDE.md) |
| Easy mode | Copilot-assisted authoring, review, push, and validation of a source-controlled Copilot Studio project. GitHub Copilot-only is the default; Brainstem is an optional lane. | [Delivery mode definitions](../solutions/README.md) |
| Evidence boundary | The limit of what an artifact proves: synthetic workflow evidence is not a customer KPI or proof of a live connection; a screenshot proves only the visible state in that frame. | [Field-guide evidence boundary](../solutions/ask-hr/FIELD-GUIDE.md) |
| Evidence gates | The field guide's Source, Easy, Manual, Parity, Draft, and Customer checks covering inputs, captured validation, matched build inventories, publication state, and production agreements. | [Field-guide evidence gates](../solutions/ask-hr/FIELD-GUIDE.md) |
| Evidence report | A package's `evidence-report.html`, presenting recorded deterministic and visual evidence. Opening it is a static evidence review, not a live deployment or validation run. | [Package structure](../solutions/README.md), [permit seller quick start](../solutions/building-permit-processing/README.md) |
| Export bundle | Downloadable package assets under `exports/`, including source and Copilot Studio solution bundles; `export-manifest.json` records the file and bundle contract. | [Package structure](../solutions/README.md), [Ask HR package map](../solutions/ask-hr/README.md) |
| Field guide | The facilitator and learner guide for inspecting source, reproducing a synthetic workflow, reviewing a deployment blueprint, and identifying production integration requirements. | [Ask HR field guide](../solutions/ask-hr/FIELD-GUIDE.md) |
| Global instructions | The manual build's reviewed role, allowed sources, routing, response rules, and safety boundaries in `manual/GLOBAL-INSTRUCTIONS.md`. | [Ask HR global instructions](../solutions/ask-hr/manual/GLOBAL-INSTRUCTIONS.md) |
| Grail | The pinned upstream source of the Brainstem kernel that AIBAST vendors. AIBAST integrations grow around that kernel rather than creating an independent runtime fork. | [Grail species contract](../docs/GRAIL-SPECIES.md) |
| Hippocampus | The separately offered Tier 2 cloud-backend path for Azure Functions and persistent memory. It does not require taking the local Brainstem installation path first. | [Cloud-backend introduction](../README.md), [repository layout](../CLAUDE.md) |
| Journey stage | A catalog label for the workflow's business role, such as `Empower` for Ask HR or `Govern` for Building Permit Processing; not an agent quality tier. | [Solution catalog](../solutions/catalog.json), [quality-tier definitions](../CONSTITUTION.md) |
| Kernel sync | A reviewed update from the pinned Grail source, accompanied by refreshed species and drift records and delivered through the staging release process. | [Release process](../docs/RELEASE-PROCESS.md), [Grail species contract](../docs/GRAIL-SPECIES.md) |
| Manual mode | Literal construction in the Copilot Studio browser using the reviewed instructions, knowledge, skills, model, and Preview cases. It is not PAC CLI authoring or YAML import. | [Manual delivery steps](../solutions/ask-hr/FIELD-GUIDE.md) |
| Manual tutorial | A package's screenshot-by-screenshot build guide. Each action has an expected result and evidence boundary; an open tutorial step is not proof that the action was captured. | [Package structure](../solutions/README.md), [manual delivery steps](../solutions/ask-hr/FIELD-GUIDE.md) |
| Nervous System | Tier 3: the Copilot Studio and Teams layer for delivery into Microsoft 365 experiences. | [Three-tier architecture](../CLAUDE.md), [Tier 3 introduction](../README.md) |
| One-pager | The approved solution slide specifying its advertised name, summary, scenario, and capability promises. Each advertised capability must map to implemented behavior. | [Agent Constitution](../agents/@aibast-agents-library/AGENT_CONSTITUTION.md) |
| Preview | The Copilot Studio test conversation used to replay locked cases before publication. Manual validation uses a fresh conversation for each unchanged prompt. | [Manual delivery and acceptance](../solutions/ask-hr/FIELD-GUIDE.md) |
| Production replacement seams | Named boundaries where approved system connections replace synthetic inputs while preserving the reviewed input/output contract. They are not evidence that a live connector is already configured. | [Permit production seams](../solutions/building-permit-processing/manual/GLOBAL-INSTRUCTIONS.md), [field guide](../solutions/building-permit-processing/FIELD-GUIDE.md) |
| Promotion | For repository releases, the human-merged pull request that moves a gated staging candidate into production `main`, followed by a release-ledger entry. Distinct from choosing a deployment tier. | [Release process](../docs/RELEASE-PROCESS.md), [tier definitions](../CLAUDE.md) |
| Quality tier | The manifest's review and maintenance classification: `community`, `verified`, or `official`. This is separate from the local, Azure, and Copilot Studio deployment tiers. | [Constitution](../CONSTITUTION.md), [deployment tiers](../CLAUDE.md) |
| Quest | A package's guided Easy/Manual workshop page, `quest.html`. It takes the learner through a build rather than serving only as a reading list. | [Package structure](../solutions/README.md), [workshop field notes](../field-notes.json) |
| RAPP | Rapid Agent Prototype Pattern, the platform and methodology used to publish, discover, install, and prove portable agent templates. | [Constitution](../CONSTITUTION.md), [project introduction](../README.md) |
| Registry | `registry.json`: the generated inventory used by the library site, built from agent manifests and carrying stack and solution metadata. | [Library introduction](../README.md), [registry](../registry.json) |
| Release gate | The seven solution checks connecting one-pager promises, synthetic problem data, isolated routing, deterministic results, captured transcripts, transcript-backed demos, and Copilot Studio replay before publication. | [Solution release gate](../solutions/README.md) |
| Single File Principle | One portable agent is one Python file containing its docstring, manifest, `BasicAgent` subclass, and `perform()` entry point. A separate solution package supplies delivery assets. | [Constitution](../CONSTITUTION.md), [package boundary](../solutions/README.md) |
| Skill | A named `SKILL.md` procedure packaged for upload to Copilot Studio and selected through the agent's routing instructions. | [Example Ask HR skill](../solutions/ask-hr/manual/skills/aibast_leave-balance_01/SKILL.md), [routing instructions](../solutions/ask-hr/manual/GLOBAL-INSTRUCTIONS.md) |
| Solution package | Customer-facing and deployment assets under `solutions/<slug>/`, including workshop pages, a manual kit, evaluation records, screenshots, and exports alongside the portable agent. | [Package contract](../solutions/README.md) |
| Spinal Cord | Tier 2: the Azure Functions and Azure OpenAI cloud-hosted layer. | [Three-tier architecture](../CLAUDE.md) |
| Stack | A group of agents for one industry scenario. The registry records its member agents and vertical. | [Library introduction](../README.md), [stack inventory](../registry.json) |
| Staging ring | The maintainer-fork `staging` branch and its candidate site and installer, gated before a human promotes changes to production. | [Release process](../docs/RELEASE-PROCESS.md) |
| Synthetic snapshot | The fixed fictional records and rules used by a packaged manual pilot. They are not current customer data or a live lookup. | [Ask HR snapshot](../solutions/ask-hr/manual/GLOBAL-INSTRUCTIONS.md), [permit snapshot](../solutions/building-permit-processing/manual/GLOBAL-INSTRUCTIONS.md) |
| Tier | A self-contained deployment layer: local Brainstem, Azure Spinal Cord, or Copilot Studio Nervous System. Advancing through every tier is optional. | [Three-tier architecture](../CLAUDE.md) |
| Tool | The callable capability the runtime exposes from an agent's metadata and `perform()` method. Its callable name is distinct from the publisher-qualified package name. | [Agent Constitution](../agents/@aibast-agents-library/AGENT_CONSTITUTION.md) |
| Transcript corpus | The canonical isolated Brainstem runs in `evals/transcripts.json`, used as the source for static demos and downstream Copilot Studio acceptance tests. | [Source-of-truth boundaries](../solutions/README.md), [Ask HR transcripts](../solutions/ask-hr/evals/transcripts.json) |
| Vertical | The industry grouping used to organize stacks and filter the library, such as human resources or state and local government. | [Library introduction](../README.md), [registry stack metadata](../registry.json) |
