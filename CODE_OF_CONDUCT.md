# Code of Conduct

This project follows the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

Participants in repository issues, pull requests, Discussions, workshops,
badge programs, and other community spaces are expected to follow that policy.
Questions or reports about conduct may be directed to
<opencode@microsoft.com>.

See the
[Microsoft Open Source Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
and [Microsoft moderation support](https://aka.ms/opensource/moderation-support)
for additional guidance.
