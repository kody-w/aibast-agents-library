# Workshop playbooks

The AIBAST Easy Mode workshop skills read this index at run time, from the
same pinned commit as the workshop, and follow the playbook that matches the
user's situation. Adding a playbook here, with one line in the list below,
extends every workshop skill without changing the skill files.

| Playbook | Use it when |
| --- | --- |
| `adapt-and-connect.md` | The user needs something different from the library version (another process, other data, another report, another system), or asks how to connect live systems such as Dynamics 365, Excel, SharePoint, or a finance system. |
| `build-it-yourself.md` | Nothing in the library comes close to the user's need, or the user wants to build a new agent from the start. |
